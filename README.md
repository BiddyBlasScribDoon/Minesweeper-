# Minesweeper

Classic Minesweeper for Windows, written in C++ with the native Win32 API.

## Download
Open the **Actions** tab, click the latest green run, and download the
**Minesweeper-exe** artifact at the bottom. Unzip it and run `Minesweeper.exe`.

## Controls
- Left click: reveal
- Right click: flag / ? / clear
- Middle click or left+right: chord
- F2 or the smiley: new game
